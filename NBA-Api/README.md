This uses the nba_api Python package to search for NBA players and get season averages and game logs from stats.nba.com. The player searches use nba_api.stats.static.players, and PlayerCareerStats and PlayerGameLog are called with a player ID and season and return Python dictionaries/lists. No API key or authentication is required but to run the project, install `pip install -r requirements.txt`, then run `python nba_cli.py` in the terminal
